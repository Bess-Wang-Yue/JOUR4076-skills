# JOUR4076 Skills

Skills for WorkBuddy used in JOUR4076 (HKBU, Semester 1 2026/27).

## sketch-to-prototype

把手繪線框圖（照片或掃描圖）轉成可點擊的 HTML 網頁原型，並附設計說明。設計決定由你們在紙上做；這個 skill 只負責把草圖忠實地做成原型。

### 安裝

1. 在這個頁面按綠色的 **Code** 按鈕 → **Download ZIP**。
2. 解壓縮下載的檔案。
3. 把裡面的 `sketch-to-prototype` 文件夾，整個放到 WorkBuddy 的 skills 文件夾：`~/.workbuddy-ai/skills/`
   - Mac：在 Finder 按 `Cmd + Shift + G`，輸入 `~/.workbuddy-ai/skills/`，按 Enter。
4. 重新開啟 WorkBuddy。

### 使用

1. 在紙上手繪線框圖，用粗筆寫清楚每個區塊的名稱，並在旁邊寫上對應的 Part A 發現編號。一張紙畫一個頁面。
2. 拍照（光線充足、正面拍攝）。
3. 在 WorkBuddy 上傳照片，並輸入：「用 sketch-to-prototype，把這張手繪線框圖做成原型。」
4. WorkBuddy 會先複述它讀到的區塊，並問你三個問題。確認後才會製作原型。
5. 打開生成的 `index.html`，在手機和電腦上試用。按右下角「設計說明」，檢查每個區塊的理由。

### 界線

- 原型忠於草圖，不會自行增加或調換區塊。
- 不會虛構客戶資料；沒有提供的內容會顯示為【待填】。
- 表格按鈕不會真的提交任何資料。
